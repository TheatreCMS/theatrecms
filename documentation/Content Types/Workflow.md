A typical workflow would be as follows:

1. Create a [[Season|Seasons]]
2. Create [[People]] as needed (optional)
3. Create a [[Works]] post 
4. Create a [[Productions]] post

As an example, let us say my theatre will be doing _Romeo and Juliet_ this year. As I am just now setting up Theatre CMS for the ensemble:

1. First, I need to create a `Season`. I can specify a label, start and end dates _(optional)_, and add an optional description of the season, perhaps outlining the over-arching theme of the season's works.
2. Now, I will add William Shakespeare as a `Person` content type. This is not required to create a production, but adds to the rich content results _(which is good for SEO)_. I add his name and a biography _(optional)_, upload a head shot image _(optional)_, and click the save button. 
3. Next, I go the the `Add New Work` page in the admin dashboard  and add _Romeo and Juliet_. I can add a brief summary of the plot to the `description` field and upload an image to use as appropriate in the theme. Since I already added `William Shakespeare` as a person, I can attach him as the creator of this work and give him the label of 'Playwright'.
4. Now, I need to `Add New Production` for this specific run. I choose _Romeo and Juliet_ as the work being presented and then specify the opening and closing performance dates as the minimum required information. I can optionally add a description unique to this specific run, such as the director's notes, reviews, etc. Any ad hoc information unique to this set of performances of this work. There are also optional sections to specify performers and production team.
