At this time, there are five ways to contribute:

	1. Support the project financially via the `Sponsor` button on the project [home page]
	2. Fork the project and submit a pull request.
	3. Volunteer to contribute other [needed services](services.md)
	4. Share, like, and discuss this project on social media, helping to generate buzz about the project.

## VS Code workspace recommendations

- Open this repository in VS Code and install the recommended extensions from `.vscode/extensions.json`.
- Recommendations are workspace-scoped for onboarding consistency. They do not change your global extension installs.
