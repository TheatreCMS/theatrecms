# TheatreCMS

TheatreCMS is an open-source content management system (CMS) designed specifically for the performing arts organization  to create a website to market their performances. While the name implies a focus on theatre, the architecture and terminology is suitable for any organization that provides live performances, such as dance troupes, opera companies, symphony orchestras.

This project is born out of the confluence of three things: my own experiences as a professional actor and musician, my day job as a web developer, and my frustration building websites for three different entertainment sector clients _(a regional theater, an opera company, and a symphony orchestra)_. The first site was a collection of HTML pages I created back in the days prior to CMSes using Dreamweaver with shared templates, while the latter two were built with extensive customization of  WordPress&trade;, and the complex relationships of content entities struggled to fit into custom post types and fields.

The goal of TheatreCMS is to enable even the smallest of performing arts organizations, who typically struggle to afford venue rental fees let alone have a professional web developer on speed dial, to implement a website for their organization that is as easy to use as _(and in many cases far simpler than)_ enterprise-level offerings. 

I have always liked the core/plugin/theme architecture of WP, and TheatreCMS, therefore, adopts this pattern as well. It is, however, a completely different implementation designed to address the needs of performing arts organizations specifically. If you have experience with WordPress&trade;, TheatreCMS will definitely feel familiar but much more suited to your business needs right out of the box. The native content types model what performing arts organizations do: seasons, productions, performances, people _(actors, directors, musicians, dancers)_, and artistic works _(plays, dances, concertos, etc.)_.

**THIS IS ALPHA SOFTWARE**. At this time, it is an experiment in technologies, consumer interest, and creating an open source software project that gains a significant user base. While the code in this repository does work _(for the most part)_, it is **not ready for production**.
